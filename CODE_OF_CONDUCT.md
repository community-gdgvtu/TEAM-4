# Code of Conduct — Team 4

GDGoC Summer DevSprint 2026 is committed to providing a harassment-free, inclusive experience for everyone, regardless of experience level, gender identity, sexual orientation, disability, physical appearance, body size, race, religion, or nationality — reflecting the collaborative spirit between GDG on Campus VTU Belagavi and GDG on Campus Waseda University.

This repository and all contributions to it are governed by this Code of Conduct in addition to the [MLH Code of Conduct](https://mlh.io/code-of-conduct), which all participants agreed to at registration.

## Expected Behavior

- Be respectful and considerate toward teammates, mentors, judges, and organizers, across time zones and language differences.
- Communicate constructively in issues, pull requests, and commit messages.
- Credit teammates and third-party sources appropriately.
- Respect shared resources (sponsor API keys/credits, repository access) — use only for Team 4's DevSprint project.

## Unacceptable Behavior

- Harassment, discriminatory jokes or language, or personal attacks in any repository space (issues, PRs, commits, discussions).
- Submitting plagiarized or maliciously altered code.
- Sharing repository or sponsor credentials outside the registered team.
- Disruptive behavior that undermines a teammate's ability to contribute.

## Scope

This Code of Conduct applies within this repository (commits, issues, pull requests, discussions) and at all associated DevSprint venues — in person, on the event Discord/WhatsApp, and during judging.

## Reporting

If you experience or witness unacceptable behavior, report it to the GDGoC Summer DevSprint 2026 organizing committee (GDG on Campus VTU Belagavi / GDG on Campus Waseda University) or via the official MLH reporting channel. Reports will be handled promptly and confidentially.

## Enforcement

Organizers may issue a warning, revoke repository access, or disqualify Team 4 from judging for violations of this Code of Conduct, at their discretion and proportionate to the severity of the incident.
